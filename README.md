# span018 — Present & Preterite

Study online: https://esemmelman.github.io/span018/

All 15 infinitives from [spa017](https://esemmelman.github.io/spa017/), in their original order. Each verb has two columns: present and preterite, with all six subject forms, accents, and reflexive pronouns. Includes Spanish/English search and a print button.

Open `index.html` for offline use. No dependencies or runtime build needed. GitHub Pages publishes the root of `main` automatically after pushes.

`build.py` regenerates the static HTML using the verb bank in the adjacent `../span017/index.html` source project. The generated HTML is committed so deployment does not need that adjacent project.
